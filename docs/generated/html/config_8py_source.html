56 """
57 Parameters for a 3D simulation. They are similar to the 2D parameters, but with a few differences. The main difference is that the slit height is specified in micrometers, and the slit height in cells is calculated from that. The other difference is that the number of cells in the z-direction is specified, and the slit shape is set to "rectangular". The slit width and spacing are also specified in micrometers, and converted to cells using the um_to_cells parameter.
58 """
