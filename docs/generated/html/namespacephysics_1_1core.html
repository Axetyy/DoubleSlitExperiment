Detailed Description

Unified physics implementations for 2D and 3D simulation backends.

CPU-optimised version: the whole time step (stencil, damping, wall mask,
source injection, detector averaging) is fused into one parallel Numba
kernel.

One leapfrog step, fused.

un = mask * ( dn * (2u + C2*lap(u)) - dn*dp * up + source )
with c_next = dn*mask and c_prev = dn*dp*mask precomputed.
Border cells have lap == 0

:param u: current field
:param up: previous field
:param un: next field (output)
:param c_next: precomputed damping * mask for next field
:param c_prev: precomputed damping * damping_prev * mask for previous field
:param C2: courant^2
:param sy: y-coordinate of the source
:param sx: x-coordinate of the source
:param sv: source value to inject
:param x0: left edge of the detector
:param x1: right edge of the detector
:param I_det: detector intensity accumulator (output)
:param avg: number of steps to average over for the detector

44 """One leapfrog step, fused.
45
46 un = mask * ( dn * (2u + C2*lap(u)) - dn*dp * up + source )
47 with c_next = dn*mask and c_prev = dn*dp*mask precomputed.
48 Border cells have lap == 0
49
50 :param u: current field
51 :param up: previous field
52 :param un: next field (output)
53 :param c_next: precomputed damping * mask for next field
54 :param c_prev: precomputed damping * damping_prev * mask for previous field
55 :param C2: courant^2
56 :param sy: y-coordinate of the source
57 :param sx: x-coordinate of the source
58 :param sv: source value to inject
59 :param x0: left edge of the detector
60 :param x1: right edge of the detector
61 :param I_det: detector intensity accumulator (output)
62 :param avg: number of steps to average over for the detector
63
64 :return None: modifies un and I_det in place
65 """
66 ny, nx = u.shape
67 two = np.float32(2.0)
68 four = np.float32(4.0)
69 inv_w = 1.0 / (x1 - x0 + 1)
70
71 for i in prange(ny):
72 if i == 0 or i == ny - 1:
73 for j in range(nx):
74 un[i, j] = c_next[i, j] * (two * u[i, j]) - c_prev[i, j] * up[i, j]
75 else:
76 un[i, 0] = c_next[i, 0] * (two * u[i, 0]) - c_prev[i, 0] * up[i, 0]
77 un[i, nx - 1] = (
78 c_next[i, nx - 1] * (two * u[i, nx - 1])
79 - c_prev[i, nx - 1] * up[i, nx - 1]
80 )
81 for j in range(1, nx - 1):
82 lap = C2 * (
83 u[i + 1, j] + u[i - 1, j] + u[i, j + 1] + u[i, j - 1]
84 - four * u[i, j]
85 )
86 un[i, j] = c_next[i, j] * (two * u[i, j] + lap) - c_prev[i, j] * up[i, j]
87
88 if i == sy:
89 un[i, sx] += sv
90
91 # detector: running mean of u^2 over the last columns, float64 accumulator
92 s = 0.0
93 for j in range(x0, x1 + 1):
94 v = un[i, j]
95 s += v * v
96 I_det[i] += np.float32((s * inv_w - I_det[i]) / avg)
